# 优化020-统一消息中心与回复定位反馈

## 修改
- 私聊会话和校园回复合入消息中心，支持全部、私信、校园回复分类；旧私聊列表入口重定向消息中心，具体聊天页面保留。
- 新校园回复通知携带实际消息focus ID，进入完整对话自动加载后续分页直到目标出现。
- 定位接口校验目标属于对应对话，不可用时提示并保留对话入口。
- 滚动结束且目标可见稳定后才播放按压动画；对应消息带内阴影，周围消息轻度灰化，2.4秒恢复。
- 尊重系统减少动态效果设置，使用静态描边替代动画。
- 消息中心一键已读同时清除会话未读角标。

## 验证
- Java与Vue构建通过；完整回归10组通过、0失败。
- 新增回归55条回复跨首批50条的定位、精确通知链接、目标及跨对话校验。
- 浏览器目标第55条自动出现于视口top约395/bottom约531（视口720高）；已捕获按压动画与灰化截图。
- 修复测试发现的450ms定时早于长距离滚动结束，改为逐帧检查可见稳定后触发。

## 说明
历史通知仅保存原对话地址，不猜测具体回复；新通知携带精确回复ID。效果只作用于对话内消息，不用全屏遮罩阻挡导航操作。
