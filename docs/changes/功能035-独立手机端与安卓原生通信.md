# 功能035-独立手机端与安卓原生通信

## 功能与架构

新增 `mobile-app/`，使用 Vue 3、TypeScript、Vite 与 Capacitor 7.6.10，生成 Android SDK 35 / Java 21 工程。手机端拥有自己的校园登录页、首页、底部导航、页面样式和系统返回行为，共用原 Java API、数据库与前端业务组件，避免复制后形成两套业务实现。

覆盖出售/求购、失物/招领、自己的管理主页、他人主页、资料修改、发布编辑、系统选图上传、私信、通知、校园地点讨论和 RAG 助手。手机市场每组 1 件，电脑端保持默认 3 件；地图增加单指拖动与双指缩放。静态校园图片、海妖和分级地图从原前端复制到构建产物，排除 40 MB 地图母图。清理新工程未使用的默认模板图标、启动图及示例测试。

## 原生通信与会话

- Android 使用 Capacitor HTTP/XHR 桥处理 API 和 multipart，继续使用服务端 Session 与 CSRF，不新增持久登录，也不把模型密钥打包进 App。
- 受保护头像和图片通过原生请求转换为临时 Blob URL；组件卸载后释放。业务与上传数据继续保存于原数据库。
- 新增 Android `CampusStreamPlugin`，仅支持通知 GET 和助手 POST 两条 SSE 路径，流式转发事件；并发最多 2，进入后台关闭连接，回到前台重连并同步。
- 服务地址单独配置，正式构建使用 HTTPS；仅 debug 允许局域网 HTTP。前后台会话静默检查，避免选择相册回来时销毁未提交表单。
- 修复旧用户名 HTML pattern 与新版 WebView 的 `v` 正则模式不兼容的问题，网页端同步修复。

## 构建、验证与限制

- `mobile-app/README.md` 记录网页预览、Android 构建、局域网与 USB ADB 映射、测试方法；提供独立 PowerShell 构建脚本。
- Gradle Wrapper 固定 8.10.2，并添加官方 SHA-256；构建缓存隔离在 `.tools/mobile-gradle`。APK、签名和构建缓存不进 Git。
- 手机网络策略/SSE 解析 4 项测试通过；手机与电脑的 TypeScript、Vite 构建通过。
- 独立 QA 数据库上的原有 13 组业务回归全部通过；另验证手机预览的同源代理、登录、头像、地图资源及未读数。
- 浏览器以 390 × 844 检查登录后的首页、自己的主页与发布弹窗。
- Android 35 模拟器实际 WebView 集成测试通过：原生 Cookie/CSRF 登录、头像读取、multipart 商品图片上传、SSE ready 事件及退出后 401，输出 `OK (1 test)`。
- 本机模拟器的分包安装失败，改用 `adb install --no-streaming` 成功；宿主机 NAT 地址连接失败，改用固定 QA 端口的 ADB reverse 成功。没有放宽后端鉴权、证书验证或正式构建的明文限制。

产物为可安装 Android debug APK。iOS 工程及通信桥、发布签名、商店发布、关闭 App 后的系统推送未实现；真实手机相册/键盘、弱网和不同机型仍需验收。QA 默认关闭 AI，本次未重复测试真实模型生成。测试只使用独立 QA 库，完成后清理；正式账号、商品和聊天不修改。
