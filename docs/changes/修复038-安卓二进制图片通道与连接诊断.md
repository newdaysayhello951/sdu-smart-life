# 修复038-安卓二进制图片通道与连接诊断

用户确认已安装037，仍然慢。本机只读统计：2份已上传头像最大936038字节、平均488325字节；2份商品图片最大47386字节、平均25447字节，SQL统计读取约1—4毫秒。这不是手机端到端耗时，也没有测到接口完整解码时间，不能据此认定网络或数据库是唯一原因。

发现037的Android图片仍通过 CapacitorHttp 将完整二进制转成Base64/JSON，过JS桥后atob再建Blob。038新增限定图片路径的本地WebView二进制处理器，携带相同Cookie访问后端，以image响应直接交给WebView，移除这段跨桥转换。

保留头像160、商品960、评论640预览与原图分支。原生内存缓存仅缓存不超过256KB的图片，最多24项、有效期30秒，键包含服务器、路径、会话Cookie及变更代数；不写静态文件。登录/退出、资料和商品修改推进缓存代数。限制HTTPS及debug局域网HTTP、固定图片路由、不跟随重定向，并保留鉴权失败状态与no-store响应。其他请求沿用原通信机制。
