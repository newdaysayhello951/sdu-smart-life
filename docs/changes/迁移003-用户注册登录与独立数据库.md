# 迁移003-用户注册登录与独立数据库

## 修改
- 接入 Spring Security、BCrypt、MyBatis-Plus、MySQL、Flyway 和参数校验。
- 在独立 sdu_smart_life 数据库建立带自增主键、唯一用户名和密码哈希的用户表。
- 提供注册、登录、当前用户、退出、CSRF 接口，使用 HttpSession 隔离用户。
- 首页接入登录注册弹窗及退出操作，保持校园背景及原有视觉。
- 新增可重复执行的认证回归脚本及环境配置说明。

## 验证
- Maven package、Vue 类型检查和生产构建通过。
- 经前端代理验证：未登录 401、注册 201、重复用户 409、错误密码 401、登录成功、不同客户端身份隔离、缺少 CSRF 403、退出后 401。

## 边界与后续
- 本次不修改原 test 数据库；旧用户尚未导入。
- 当前会话为应用内存存储，重启后需重新登录；Redis 待接入。
- 商品列表与详情、地图、交易仍待迁移。
- 回归脚本会保留一个随机命名验证账号，不涉及真实用户数据。
