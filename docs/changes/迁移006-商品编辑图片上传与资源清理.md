# 迁移006-商品编辑图片上传与资源清理

## 修改
- 在我的发布中新增商品编辑、图片上传和缩略图预览，沿用校园视觉。
- 编辑及上传仅允许商品所有者操作在售商品，历史商品不错误绑定新用户。
- 图片限制5MB、JPEG/PNG及1600万像素；实际解码并重新编码，随机文件名保存，独立读取接口返回固定PNG类型。
- 上传目录支持环境变量配置并排除Git，数据库只保存图片地址。
- 清理未引用的旧光标、零字节图片、旧画廊装饰图；继续保留可复用校园美术资源。

## 验证

- 编辑成功、跨用户编辑与上传拒绝、无效图片拒绝、图片上传读取、数据库地址更新及下架后上传拒绝通过。
- 注册登录、CSRF、会话隔离及商品浏览搜索分页回归通过。
