# 功能025-新增失物回家与海棠猫发布入口

## 功能
- 主导航新增失物回家，上方失物寻找、下方宝贝回家；复用三条一组的滑动分页、进度点和搜索，支持名称、描述、地点。
- 自己的个人主页新增山大印章与海棠猫 SVG 按钮，弹窗选择发布类型并填写名称、描述、地点、可选图片。丢失或拾取时间在描述中填写。
- 详情可查看发布者主页、联系发布者私聊；自己的发布支持编辑、图片替换、结束寻找。
- LOST/FOUND 与二手市场 SELL/WANTED 隔离，失物不显示价格；服务端验证失物金额为零、商品金额大于零。
- 复用 MySQL 发布表及图片 BLOB、所有权校验与事务，未新增静态用户数据或数据库迁移。

## 验证
- 后端 Maven 单元测试和打包通过（4 项单元测试）。
- Vue TypeScript 检查与 Vite 生产构建通过。
- 独立临时 MySQL 数据库中执行 12 组接口回归全部通过，测试库由运行器自动删除。
- 新增检查覆盖两类发布、地点搜索、市场隔离、编辑持久化、越权拒绝、结束后列表移除及金额校验。
- 浏览器预览尝试遇到 target closed，未完成本轮人工视觉验收。

## 使用
登录后进入个人主页发布，导航「失物回家」查看。新版本重启后需重新登录（会话仍按现有设计保存在内存）。
