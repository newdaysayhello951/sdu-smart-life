# 功能032-山海校园全屏地图

点击校园地图图片或“展开山海校园”入口，打开覆盖整个网页视口的地图。采用深海色背景、金色罗盘、环形纹饰、展开亮度过渡与地图浮现动画，保留原始青岛校区规划图与数据库地点数据。

全屏内支持拖动、滚轮或按钮缩放（100%—600%）、复位；悬停、键盘聚焦或点击建筑显示名称和讨论数量，进入讨论会关闭地图并打开原有地点讨论。支持关闭按钮和 Escape，系统减少动态效果偏好下关闭入场动画。手机可单指拖动和按钮缩放。

验证：Vue TypeScript 检查和 Vite 生产构建通过，git diff --check 通过。未登录真实账号进行浏览器交互验收，视觉效果仍需实际页面确认。本次无数据库结构或业务数据修改。

当前实现是保留原始规划图的游戏地图风格全屏查看器，未将规划图重绘为游戏地形插画。
