# 重构019-牵线市场公开主页私聊与消息通知

## 平台定位
按用户要求，改为信息牵线与线下沟通。移除交易订单Controller、页面、入口及过时测试；保留历史数据库表与原有状态，不删除、不取消、不重新上架。旧订单功能不再参与当前流程。

## 市场与主页
- 新增SELL/WANTED分类，自己主页可发布出售或感兴趣/求购，求购可不带参考图。
- 市场出售与求购分区，初始各3条；手指、鼠标横滑、滚轮、按钮和进度点均按页请求，不一次拉取全部。
- 商品详情展示发布者头像、ID与用户名，联系发布者进入一对一私聊。
- 市场和校园评论头像链接到独立公开主页，公开资料、出售和求购按需加载。
- 自己主页保留编辑、管理及通知入口；打开自己的公开地址重定向回管理页。

## 私聊与通知
- 数据库保存会话和消息，用户对唯一约束，双方同时发起只创建一个会话。
- 仅双方可访问、发送和标记该会话已读；支持双向文字与Emoji。
- 顶部气泡未读数1至98显示真实数，99及以上显示99；0不显示红角标。
- 通知包含私信与校园回复；未读独立标记，单条、一键及会话已读均存数据库。
- 一键已读按当前消息快照上界标记，新到通知保持未读。
- 消息每3秒、气泡每5秒刷新，退出页面清理轮询；活跃消息滚动到底部。
- 用actor_id及稳定用户ID关联，改名后公开页、会话对方、历史消息作者及历史通知同步新用户名。

## 数据
业务字段、头像、商品与讨论图片、求购、私聊、通知、已读状态都入MySQL；固定美术素材继续静态托管。未上传用户资料到Git。旧商品未映射用户时不错误归属新账号。

## 验证
- Java package、Vue类型检查和生产构建通过，diff检查通过。
- scripts/run_regression.py汇总9组回归，9通过0失败。
- 新增验证出售/求购分页与归属、公开资料不含密码、并发建立同一私聊、双方互聊、第三方读写拒绝、101条未读、单条及快照一键已读、消息游标无重复、改名后所有展示更新。
- 浏览器验证进度点换页、他人主页无管理控件、自己主页管理入口、公开主页联系并发送私信。
- 浏览器101条未读显示99，未读黄色卡片及红点，一键已读后标记及角标消失。

## 测试修复
- 修复MySQL重复读下并发创建会话的旧快照查询，使用当前读返回同一会话。
- 修复通知标题拼接ascii用户名与中文时字符集冲突。
- 资料回归原先整对象比较忽略用户名动态字段，已改为检查稳定关联不变且用户名同步。

## 审批与保留
自动审批拒绝取消已有预订并重上架，已移除该操作；采取保留历史状态的安全方案，没有绕过拒绝。

## 当前边界
私聊为文字/Emoji，图文附件仍在校园讨论；消息更新采用短轮询而非WebSocket。历史商品用户映射及旧交易数据不自动猜测。未做生产规模负载测试。
