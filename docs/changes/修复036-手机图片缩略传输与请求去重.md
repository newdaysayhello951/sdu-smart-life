# 修复036-手机图片缩略传输与请求去重

商品图片原接口返回完整 PNG（可达数 MB）且禁止缓存，手机图片指令还会为重复头像和图片各自发起原生下载，增加热点传输与桥接开销。

新增商品图片 `w` 参数：0 保持原始响应，1—1280 返回限制最长边的 JPEG 预览，保留宽高比和数据库原图。手机使用 960 像素预览。原接口鉴权和 no-store 保持不变。

手机端增加 30 秒内存下载结果缓存（最多24项），合并相同图片的并发请求，最大同时下载4张。非 GET 请求清空缓存，使退出、登录、发布、修改头像等操作后的图片重新获取。不保存到设备静态文件。此优化主要针对图片；未证明所有普通信息接口均存在相同瓶颈。

验证：后端原有7项单元测试、手机 TypeScript/Vite 构建；新增图片测试验证2400×1600原图缩至960×640，体积小于原图四分之一，原始字节保持不变及非法尺寸拒绝。Android调试包重新构建。本地后端更新；未获得真机更新后的耗时测量，不承诺固定加载速度。手机需安装新版 APK，正式数据未修改。
