# 修复033-全屏校园地图原图清晰缩放

原图为 8410 × 11890 像素。本次将全屏地图的 CSS scale 整层放大改为实际布局宽高变化，使浏览器按当前显示尺寸渲染原图，移除地图容器模糊、亮度滤镜及持续的合成层提示。原图及热点坐标保持不变。

缩放上限由全图的 6 倍增加至 24 倍，增加“原图细节”按钮（按设备像素比计算目标尺寸，受缩放上限约束），原“复位”改为“全图”。滚轮围绕鼠标缩放，拖动边界限制在地图范围内，窗口改变时重新计算适配尺寸。

验证：Vue TypeScript 检查、Vite 生产构建与 git diff --check。未使用真实账号登录验收，最终文字清晰度需在实际屏幕上确认。没有数据库修改。
