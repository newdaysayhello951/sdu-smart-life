# 迁移018-交易订单与并发防重复成交

## 功能
- 商品详情新增预订入口，个人主页新增我的交易记录。
- 买卖双方可查看自己的订单，游标加载更多。
- 预订锁定商品RESERVED，双方可取消并恢复AVAILABLE，仅买家可确认收货并标记SOLD。
- 订单保存商品标题、成交价格快照和买卖双方用户ID；账号改名不丢失关联。
- 事务以商品行锁串行化，同一商品并发只允许一笔有效订单。
- 同一买家重复预订返回现有订单，重复取消/完成幂等，错误状态转换返回409。
- 防止购买自己的商品、第三方查看/操作订单及卖家冒充买家确认收货。
- 未确认历史卖家的商品暂不可交易，不猜测归属。

## 验证
- Java构建及Vue类型检查/生产构建通过。
- check_orders.py通过：自购拒绝、两个买家并发单胜、重试幂等、取消恢复、越权拒绝、卖家确认拒绝、买家完成及重复完成、订单价格快照、第三方列表隔离、非法游标。
- 登录/发布、个人资料/改名关联、图文对话回归通过。
- git diff --check通过。

## 范围
此流程记录校园线下交接，不接在线付款；未实现超时自动取消、争议处理与退款。旧record表尚未导入，需先建立可靠的历史用户映射。未执行此批浏览器视觉验收。
