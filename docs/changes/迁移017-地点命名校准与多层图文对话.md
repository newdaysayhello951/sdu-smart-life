## 对话功能
- 顶层评论下默认显示最早两条回复及总回复数。
- 回复输入框紧随对应评论或回复，支持回复回复，显示所回复用户名和消息编号。
- 查看对话详情进入独立页面，按时间升序加载全对话，每批50条，支持继续加载。
- 左侧头像、上方名称与时间、下方文字及图片。
- 支持Emoji快捷按钮、PNG/JPEG/GIF表情包；图片最大显示240×180，按比例缩放，点击原图。
- 图片二进制存数据库；服务器仍执行附件5MB、像素及GIF帧数校验，显示限制与上传限制分别处理。
- 本人删除文字及图片，保留占位和回复引用。
