# 修复037-头像评论图片与手机预加载优化

检查发现：本人/他人头像都返回完整上传PNG，评论附件也是原图；隐藏原图弹窗提前下载；手机图片指令绕过浏览器 loading=lazy，屏幕外图片仍提前走原生桥；任何非GET请求（包括私信标记已读）都会清空图片缓存。

修复：本人及其他用户头像统一支持 w 参数，手机请求最长边160像素JPEG；评论非GIF预览最长边640，GIF保留原始动画。宽度0保持原图，非法宽度拒绝。商品预览维持036逻辑。原图弹窗仅在打开时创建图片，原图不会被替换为缩略图。数据库与原始数据不变。

手机使用 IntersectionObserver 在距离视口200px内启动图片下载，卸载清理观察器与Blob。已读、聊天等不相关请求不再清缓存；登录/退出、资料及商品变更仍使缓存失效。保留30秒缓存、重复请求合并、4并发和24项上限。

验证：后端原有8项测试通过；新增2项验证本人/其他用户头像最长边、原始字节保留、GIF字节保留和非法尺寸。手机与电脑TypeScript/Vite构建通过，Android重新打包。没有在正式库创建测试数据。没有真机更新后的耗时测量，也未完成超长私聊历史、通知历史的专项压力测试，不能宣称所有数据瓶颈均已消除。

后端本地更新需要重新登录；手机需安装037新版APK。APK、缓存和密钥不提交仓库。
