# 迁移004-商品市场与详情及旧数据导入

## 修改
- 增加商品 Controller / Service / Mapper 分层及 Flyway V2 建表脚本。
- 提供匿名可访问的商品列表、关键词搜索、分页及详情接口，限制分页与关键词参数。
- 使用 Vue Router 接通首页、市场与详情，支持浏览器返回和详情地址刷新。
- 市场沿用原校园背景；商品照片采用独立文件，提供加载、空结果、错误和重试状态。
- 增加显式旧商品导入脚本：只读源库，独立目标库，按旧编号去重，校验金额和图片格式，冲突地点留空。

## 验证
- Java package 与 Vue 类型检查、生产构建通过。
- 本地导入 9 件商品，0 件跳过；重复导入新增 0 件。
- 原地点编号 2 对应多个名称，未猜测关联，保留为待补充。
- 商品回归通过：列表、详情、图片、详情地址响应、搜索、空结果、分页不重复、非法参数 400、不存在商品 404。
- 登录、注册、退出、身份隔离及 CSRF 回归通过。
- git diff --check 通过；未进行浏览器视觉验收。

## 边界
- 本批仅迁移商品浏览，发布、编辑、评论、交易和真实卖家关联后续实现。
- 不修改原 test 数据库，不公开旧账号信息。
- 导出图片为本地运行数据，不随 Git 提交，其他环境需运行导入脚本。
- 旧用户映射完成前不将历史商品错误绑定到新注册用户。
