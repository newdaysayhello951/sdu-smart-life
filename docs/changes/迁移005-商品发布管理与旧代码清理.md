# 迁移005-商品发布管理与旧代码清理

## 功能
- 登录用户可以发布商品、查看自己的商品并下架。
- 新增商品归属外键，历史商品不错误分配给新账号。
- 服务端校验价格、标题、描述和地点；下架 SQL 同时校验所有者及状态。
- 个人主页入口接入我的发布；图片上传仍待迁移，新商品暂用默认图。

## 清理
- 删除 reference 下原 Flask Python 应用及全部旧 HTML 模板，历史仍可由 Git 查阅。
- 删除未被新页面引用的 legacy/css 和 legacy/js。
- 保留图片美术资源，供当前页面与后续地图迁移复用。
- scripts 下 Python 是新项目仍使用的数据导入及接口回归工具，暂保留，运行系统不依赖 Python。

## 验证
- Maven package、Vue 类型检查和生产构建通过。
- 注册登录、会话隔离、CSRF、商品浏览搜索分页回归通过。
- 发布、非法金额拒绝、我的商品、匿名拒绝、其他登录用户不能下架、本人下架通过。
- git diff --check 通过。

## 后续
图片上传、商品编辑、用户资料、地图、评论和交易仍待迁移；尚未完成浏览器视觉验收。
