# 迁移016-高清校园图片地图与地点问答

## 功能
- 使用用户提供的8410×11890青岛校区高清规划图，替换外部地图跳转入口。
- 校准130个建筑/场馆/区域热点，坐标按图片百分比保存，支持100%至400%缩放和滚动。
- 悬停建筑在鼠标附近显示名称、讨论数量及进入按钮；键盘聚焦与触屏点击可进入。
- 地点弹窗支持提问、分享、回答问题和加载更早发言。
- 回复仅允许关联同一地点的顶层问题，拒绝跨地点和多层回复；删除保留占位避免已有答案失去上下文。
- 评论数来自数据库，发言后刷新；账号仍以用户ID关联。
- 保留原3个地点和已有评论，在地点列表中可访问，未凭空指定地图坐标。

## 标注依据
名称与编号依据提供的规划图，不表示当前实景或楼宇现名。未编号建筑按方位区分。图纸标注清单与原图坐标见docs/campus-map-hotspots.json，覆盖主要建筑、院落、场馆、球场、停车场及出入口。道路和连续绿地未按每一段拆分。热点为矩形近似，复杂院落边界仍可进一步精修；尚未逐个视觉验收全部热点，不声称全部图纸细节均精确覆盖。

## 验证
- Java构建、Vue类型检查与生产构建通过。
- 校园权限、地点列表、留言、输入校验、本人删除回归通过。
- 130个热点坐标边界检查、提问回复关联、跨地点回复拒绝、多层回复拒绝和计数更新通过。
- 认证及带图发布回归通过。
- 测试发现评论构造映射顺序错误，已修正。

## 限制
底图为40MB高清文件，首次加载较大；后续可制作多分辨率切片优化。未进行本批浏览器逐点视觉验收。规划图与现实命名差异应由校园实际信息校对。
