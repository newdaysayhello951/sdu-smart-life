# 迁移015-校园地点与讨论功能

## 修改
- 校园导航接入地点浏览与讨论页面，沿用校园配色及页面框架。
- Flyway V7创建地点、留言表，留言以稳定用户ID关联，用户名变化自动反映。
- 支持地点切换、留言发布、游标加载及仅本人删除。
- 校验空白/超长留言、非法游标、无效地点及登录权限。
- 地点快速切换时忽略过期响应，避免显示错位讨论。

种子地点采用原项目名称，不虚构坐标；未导入原有评论及重复地点编号。
